#  Team E‑Commerce Website  

##  Project Description  
This repository contains a collaborative e‑commerce website project developed by students of **Platform Technology 01 (Platech01)**.  
The activity demonstrates GitHub workflows including **branching, pull requests, code reviews, and conflict resolution**.  

The project includes:  
- **Homepage (index.html)** with featured products  
- **Product Page (product.html)** showcasing items  
- **Contact Page (contact.html)** with store information  
- **Shared Stylesheet (style.css)** for consistent design  
- **README.md** documenting project details and contributions
